# GRE 词汇 · 背词网站

包含三个学习模块：

- 六选二：来自《张巍真经 GRE 等价词汇总（新）.pdf》，按 PDF 分成 5 天，共 940 条词条。
- 数学词汇：来自《GRE 数学词汇汇总（张巍老师 GRE）.pdf》，不分天，共 385 条词条。
- 1400 词：来自 `gre1400.xlsx`，每天 200 词，共 7 天、1400 条词条。

数学词汇 PDF 使用特殊字体，常规提取是乱码，词条已经用系统 OCR 识别并手工校正，保存在 `tools/math_terms.json`。

## 使用

直接用浏览器打开 `index.html` 即可，不需要启动服务器。学习进度、错词记录会自动保存到浏览器本地。

### 多设备同步（电脑 + 手机）

网站内置了带账号的轻量同步服务。启动方式：

```bash
cd 项目目录
node server/server.js
```

打开网站后先选择“注册”或“登录”：注册时取一个不重复的名字并设置密码；电脑和手机登录同一个名字，就会自动载入同一份学习档案。

### 手机不依赖电脑打开

手机要能在电脑关机时也能打开并同步，需要把项目部署到一台常开的云服务器（例如 Railway、Render、Fly.io 或任意 VPS）。

项目里已经包含 `package.json`、`Procfile`、`Dockerfile` 和 `render.yaml`，云平台一般会自动识别。

#### 不需要银行卡的部署方式（Netlify + GitHub）

项目已经内置 `netlify.toml` 和 Netlify 函数，Netlify 免费套餐不需要银行卡。

1. 注册一个免费的 GitHub 账号，新建一个空的公开仓库。
2. 在仓库网页里点击 “uploading an existing file”，把本项目的 `index.html`、`styles.css`、`app.js`、`data.js`、`server`、`package.json`、`render.yaml` 等文件拖进去并提交。
3. 注册 Netlify 账号（免费，不要求银行卡），点 “Add new site → Import an existing project”，选择 GitHub 仓库。
4. Netlify 会自动识别 `netlify.toml`，把网页和同步接口一起部署，学习档案保存在 Netlify 免费 Blob 存储中。

如果愿意绑定银行卡，也可以使用 Render：项目里的 `render.yaml` 会创建带 1GB 数据磁盘的网站服务。

#### 如果只是临时体验

可以先把本地服务通过 SSH 隧道映射成公网网址：

```bash
ssh -R 80:localhost:8000 nokey@localhost.run
```

临时隧道在电脑关机后会失效，且网址会变化；长期使用请使用上面的云服务器部署。

六选二每天的学习流程：

1. 给出一个单词，先在 6 个选项中选出中文释义。
2. 再在 6 个选项中选出等价词，每题只有 1 个正确答案。
3. 数学词汇和 1400 词两个模块只提供 6 个选项的中文释义题，因为原始资料没有等价词字段；进度、错词和档案记录规则相同。
4. 页面显示当天完成进度；当天完成后会列出并保存错误单词，可在“错词本”中随时查看或重练。

“个人档案”选项卡会记录每一次完整背词练习的日期、正确率、答错单词，并单独展示每一组首次背词的日期、正确率和错词。“我的账号”区域可以查看当前登录用户并退出登录。

电脑端答题时可以直接按键盘上的 `1` 到 `6` 选择选项，按 `Enter` 或空格进入下一题；手机端直接点击选项即可。

手机浏览器打开后，可以把网站“添加到主屏幕”，安装后像 App 一样全屏使用，并支持离线打开。

## 重新生成数据

等价词数据解析脚本在 `tools/extract_pdf.py`，默认读取桌面上的 PDF。

合并全部模块数据的脚本是：

```bash
python3 tools/build_data.py
```

脚本会重新生成 `data.js`。`gre1400.xlsx` 默认从桌面读取，也可通过环境变量 `GRE1400_PATH` 指定路径。

PDF 原表里 `fluid 不稳定的` 这一行没有等价词，网站会把它作为仅记录中文释义的词条处理，不会编造数据。
